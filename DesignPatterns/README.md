<h1>3 Types of Design Patterns: </h1>

1. Creational Patterns : These patterns manage object creation, offering control and flexibility during the instantiation process. Examples include Singleton, Factory Method, Abstract Factory, Builder, and Prototype patterns.

2. Structural Patterns : These patterns focus on combining classes and objects to create larger, more flexible structures. Examples include Adapter, Decorator, Proxy, Composite, Facade, Bridge, and Flyweight patterns.

3. Behavioral Patterns : These patterns deal with object communication, interaction, and responsibility assignment, promoting loose coupling. Examples include Observer, Strategy, Command, Chain of Responsibility, Iterator, State, Template Method, Visitor, Mediator, Memento, and Interpreter patterns.
